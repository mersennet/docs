Complete reference for JSON-RPC methods supported by Mersennet. All examples use `https://rpc.mersennet.com` as the RPC URL.

Mersennet implements the standard `eth_` namespace plus native extensions across `net_`, `web3_`, `txpool_`, `mersennet_`, `mersennet_orders_`, `mersennet_staking_`, and `mersennet_bridge_`. The privacy/ZK methods (shielded transfers, SP1 state proofs, selective-disclosure reads) also live in the `mersennet_` namespace and are documented separately in the [Shielded JSON-RPC reference](/developers/privacy/shielded-rpc).

---

## Standard Ethereum Methods

### eth_blockNumber

Returns the current block number.

**Parameters:** None

```bash
curl -X POST https://rpc.mersennet.com \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"eth_blockNumber","params":[],"id":1}'
```

**Response:**

```json
{ "jsonrpc": "2.0", "id": 1, "result": "0x1234" }
```

### eth_feeHistory

Returns base fee and reward percentiles for a range of recent blocks.

**Parameters:**

1. `blockCount`: Number of blocks in the range (hex)
2. `newestBlock`: Highest block number or `"latest"`
3. `rewardPercentiles`: Array of percentile values (e.g. `[25, 50, 75]`)

```bash
curl -X POST https://rpc.mersennet.com \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"eth_feeHistory","params":["0x4","latest",[25,50,75]],"id":1}'
```

:::note
`eth_feeHistory` returns an empty `reward` array (Mersennet has no priority tips). Some fee-estimation tooling doesn't expect this — pin a fixed `gasPrice` if estimation misbehaves.
:::

### eth_getBlockByNumber

Returns block by block number.

:::note
Only a recent window of blocks is served from memory; requests for older heights return `null`. Use an indexer for historical data.
:::

After privacy activation, this method remains public only for
header-only access. Setting `fullTransactions=true` is rejected because
full transaction metadata is not part of the post-fork public surface.

**Parameters:**

1. `blockNumber`: Block number (hex) or `"latest"`, `"pending"`
2. `fullTransactions`: `true` for full tx objects, `false` for hashes only

```bash
curl -X POST https://rpc.mersennet.com \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"eth_getBlockByNumber","params":["latest",false],"id":1}'
```

**Response:**

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "number": "0x1234",
    "hash": "0x...",
    "proposer": "0x...",
    "gasLimit": "0x...",
    "gasUsed": "0x...",
    "baseFeePerGas": "0x...",
    "stateRoot": "0x...",
    "domainEvents": [],
    "transactions": ["0x...", "0x..."]

}

  "height": 1350412,
  "epoch": 750,
  "nextEpochAt": 1351800,
  "activeSet": ["0x728b…", "0x9d39…", "0xc16b…", "0xe4c6…"],
  "consensusValidators": ["0x728b…", "0x9d39…", "0xc16b…", "0xe4c6…"],
  "validators": [
    {
      "identity": "0x728b…",
      "operator": "0x728b…",
      "selfStake": "0xd3c21bcecceda1000000",
      "delegated": "0x0",
      "votingStake": "0xd3c21bcecceda1000000",
      "commissionBps": 1000,
      "status": "active",
      "genesis": true,
      "registeredAt": 1348200,
      "jailedUntilEpoch": 0,
      "exiting": false,
      "pendingIdentity": null,
      "proposedSlots": 112,
      "missedSlots": 0,
      "totalProposed": 812,
      "timesJailed": 0,
      "benched": false
    }
  ]

```

| Field | Meaning |
|-------|---------|
| `active` | `false` before `activationHeight`; the genesis set applies until then |
| `epoch`, `nextEpochAt` | Current epoch index and the height of the next boundary (`epochBlocks` multiples) |
| `activeSet` | Identities producing blocks this epoch (sorted); `consensusValidators` is the engine's view and should match |
| `status` | `pending` (registered this epoch), `active`, `standby` (eligible, ranked below `maxValidators`), `jailed`, `exiting` |
| `proposedSlots` / `missedSlots` | Leader-slot accounting for the **current** epoch; a miss share above `jailMissBps` with at least `jailMinSlots` slots jails the validator for the next epoch (consecutive jails escalate 1, 2, 4… epochs from `jailEscalationHeight`; `timesJailed` is then the consecutive count) |
| `benched` | `true` when the validator missed 3 leader slots this epoch (misses ≥ a tenth of its proposals) and is out of the leader rotation until the boundary — from `benchHeight`; it still votes |
| `selfStake`, `delegated`, `votingStake` | Wei, hex-encoded; ranking uses `votingStake` |

### mersennet_nodeIdentity

This node's block-signing identity, its configured operator and the proof the operator needs for `registerValidator`. Meaningful on **your own node's local RPC** (it describes the node you are talking to).

**Parameters:** None

```bash
curl -X POST http://127.0.0.1:8545 \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"mersennet_nodeIdentity","params":[],"id":1}'
```

**Response**

```json
{
  "identity": "0x47a51113b276a74a624b1a245e07663a5af73e5c",
  "operator": "0x6dd9bb44ddfaba76d8868915d6fe80c3f8a932ec",
  "registrationProof": "0x…65 bytes…",
  "version": "Mersennet/0.7.0-ecba1ee"
}
```

`registrationProof` is the node key's EIP-191 signature over `Mersennet validator registration v1\noperator: 0x<operator>\nidentity: 0x<identity>`; it only binds identity to operator and is safe to publish. `operator` and the proof are `null` when `p2p.operator_address` is not configured.

## MersennetOrders CLOB Methods

The native order book engine accessible via RPC. The CLOB precompile is at address `0x0000000000000000000000000000000000000100`.

**Orders route through consensus.** State-mutating CLOB calls (`submitOrder`, `cancelOrder`, `depositCollateral`) do not mutate state synchronously — they build a precompile transaction, submit it to the mempool, and return `{ accepted, txHash }`. The order takes effect when the transaction mines (~1-2 blocks, a few seconds). Poll `mersennet_orders_getOpenOrders` or subscribe to the `MersennetOrdersTrades` WebSocket topic to observe the result.

On the public testnet the unsigned RPC path is **disabled** (`mersennet_orders.allow_unsigned_orders_rpc = false`, the default). State-mutating CLOB calls must be submitted as wallet-signed transactions to the precompile at `0x…0100` via `eth_sendRawTransaction` — see [Deployed Contracts](/resources/contracts/) for the Solidity interface. The unsigned `mersennet_orders_submitOrder`/`cancelOrder`/`depositCollateral` RPCs return error `-32604` unless a node is run locally with `allow_unsigned_orders_rpc = true`.

### mersennet_orders_addMarket (disabled)

This RPC method is disabled: adding a market over RPC would mutate only the node that received the call, forking the CLOB state across the network. Calling it returns a `-32601` error explaining this. The same applies to `mersennet_orders_setMarginParams` and `mersennet_orders_liquidate`.

Market creation is instead **permissionless through consensus**: call `createMarket(bytes32 symbol, uint256 tickSize, uint256 lotSize)` on the CLOB precompile (`0x…0100`) with a wallet-signed transaction. A listing fee of 100 MRSN is charged from the caller into the CLOB insurance fund. Duplicate symbols and zero tick/lot sizes are rejected. Newly created markets appear in `mersennet_orders_getMarkets`.

---

### mersennet_orders_getMarkets

List every CLOB market (genesis-seeded and permissionlessly created), sorted by id.

**Parameters:** none

**Response:**

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": [
    { "id": 1, "symbol": "MRSN", "tickSize": "0x1", "lotSize": "0x1", "lastPrice": "0xfde8", "priceScale": 1, "status": "active" }
  ]
}
```

`priceScale`: on-chain prices for the market are **human price × priceScale** (1 = integer prices). From block 1,569,600 MRSN, SOL and ARB carry `priceScale = 100`, so a price of `11500` means $115.00 and the finest tick is $0.01; sizes are unchanged and notional = price × size ÷ priceScale. Read it from this method rather than assuming integers.

### mersennet_orders_submitOrder

Submit a limit order to the CLOB. The order is packaged as a `placeOrder` precompile transaction and mined through consensus.

**Parameters:**

1. `orderObject`:
   - `owner`: Trader address
   - `market_id`: Market ID (integer)
   - `side`: `"buy"` or `"sell"`
   - `price`: Limit price (hex)
   - `size`: Order size (hex)
   - `tif`: Time-in-force: `"gtc"` (Good-Til-Cancel), `"ioc"` (Immediate-or-Cancel), `"fok"` (Fill-or-Kill)

**Local dev node only** — the unsigned RPC path requires `mersennet_orders.allow_unsigned_orders_rpc = true`; public endpoints return `-32604`:

```bash
curl -X POST http://localhost:8545 \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","method":"mersennet_orders_submitOrder","params":[{"owner":"0x7f5ce38fb2553e95dd8ef9182a80bc219c9a0d45","market_id":1,"side":"buy","price":"0xfde8","size":"0x64","tif":"gtc"}],"id":1}'
```

**Response:**

```json
{
  "jsonrpc": "2.0",
  "id": 1,
  "result": {
    "accepted": true,
    "txHash": "0xc180addcc72d1655a210238bd8d6f21dae84df21d1e6175c4f56b643ed530ca1"
  }
}
```

### mersennet_orders_getAgents

Agent delegation (one-click trading): the agent keys an account has granted, and whether the feature is active on the network.

An account grants a second key permission to trade for it with `setAgent(address agent, uint64 expiresAtBlock)` on the CLOB precompile (`0x…0100`); `revokeAgent(address agent)` ends it; `agentOf(address agent)` returns `(owner, expiresAtBlock)`. Transactions signed by an agent place and cancel orders **as the owner** — orders, positions and fills stay on the owner's account — while `depositCollateral` / `withdrawCollateral` and `setAgent` itself are never delegated. One agent key acts for one owner; an agent cannot grant agents; `expiresAtBlock = 0` means no expiry, otherwise at most ~90 days ahead. **Who is the caller?** From block 1,605,600 (`frameCallerHeight`) the precompile authorises on the call frame's `msg.sender`: a transaction sent directly acts as its signer, a contract calling the precompile acts as the contract. Before that height the transaction origin was used everywhere. The trade terminal's one-click trading is built on this (Settings → One-Click Trading).

**Parameters:**

1. `address`: Owner address (hex)

```json
{
  "owner": "0x…",
  "agentDelegationHeight": 1650000,
  "active": true,
  "frameCallerHeight": 1605600,
  "frameCallerActive": true,
  "height": 1651234,
  "agents": [{ "agent": "0x…", "expiresAtBlock": 1710400, "expired": false }]
}
```

## Precompiles

Mersennet exposes native functionality through EVM precompiles, callable from Solidity via `eth_call` or transactions:

| Address | Name | Purpose |
|---------|------|---------|
| `0x…0100` | MersennetOrders CLOB | On-chain order book: place/cancel orders, collateral, positions, best bid/ask |
| `0x…0200` | Shielded Transfer | Private note-to-note transfer (`shieldedTransfer(bytes)`) |
| `0x…0201` | Shield / Unshield | Transparent ⇄ shielded bridge (`shield`, `unshield`) |
| `0x…0202` | Code Publication | Register/revoke a contract code attestation |
| `0x…0300` | State-Proof Verifier | Verify an SP1 state-transition proof on-chain (`verifyStateProof(bytes)`) |
| `0x…0400` | MersennetStaking | Delegate/undelegate stake, claim rewards, withdraw unbonded |

(Addresses are the 20-byte form, e.g. `0x0000000000000000000000000000000000000100`.)

:::note
The shielded precompiles (`0x0200`, `0x0201`, `0x0300`) and shielded RPC methods activate with the privacy hard fork. The transparent MersennetOrders precompile is disabled after privacy activation in favor of the shielded order path.
:::
