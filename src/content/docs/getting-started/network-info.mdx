Use the following configuration to connect to Mersennet testnet.

## Testnet Configuration

| Parameter | Value |
|-----------|-------|
| **Chain ID** | 131071 (Mersenne prime 2¹⁷−1) |
| **Network Name** | Mersennet Testnet |
| **RPC URL** | `https://rpc.mersennet.com` |
| **WebSocket URL** | `wss://rpc.mersennet.com` (subscriptions only) |
| **Block Explorer** | https://explorer.mersennet.com |
| **Faucet** | https://faucet.mersennet.com |
| **Currency Symbol** | MRSN |
| **Block Time** | ~2 seconds |

:::tip
The public WebSocket endpoint serves `eth_subscribe` streams (new heads, logs, pending transactions) only — send regular JSON-RPC calls over HTTPS. Nodes you run yourself serve WebSocket subscriptions on port 8546.
:::

## Node Operators: P2P Bootnodes

Running your own node? These are the canonical seed peers for the testnet
(UDP 30303 for gossip, TCP 30303 for block sync):

| Bootnode | Address |
|----------|---------|

| Validator 1 | `46.225.183.192:30303` |
| Validator 2 | `49.13.54.79:30303` |

The canonical node configuration (including the genesis section every node
must share) ships in the [release bundle](https://mersennet.com/downloads/)
alongside the node binary and installer — no source access required. See
[Run a Node](/validators/run-a-node/) for the full guide.

## Add Mersennet to MetaMask

import AddToMetaMask from '../../../components/AddToMetaMask.astro';

<AddToMetaMask />

Or run this code in your browser console (with MetaMask installed):

```javascript
await window.ethereum.request({
  method: 'wallet_addEthereumChain',
  params: [{
    chainId: '0x1FFFF', // 131071 in hex
    chainName: 'Mersennet Testnet',
    nativeCurrency: {
      name: 'MRSN',
      symbol: 'MRSN',
      decimals: 18
    },
    rpcUrls: ['https://rpc.mersennet.com'],
    blockExplorerUrls: ['https://explorer.mersennet.com']
  }]
});
```

:::note
Chain ID `131071` in decimal equals `0x1FFFF` in hexadecimal. Both Mersennet chain IDs are Mersenne primes: testnet is `131071` (2¹⁷−1) and mainnet will be `8191` (2¹³−1).
:::

### Usage Notes

- **MersennetOrders**: The native on-chain order book — powers [trade.mersennet.com](https://trade.mersennet.com).
- **Multicall3**: Use for batched RPC reads (wagmi, viem, and ethers.js support it).
- **WMRSN**: ERC-20 wrapped MRSN for protocols that need an ERC-20 representation.
- **MockUSDC, MockUSDT, MockDAI**: Test stablecoins with a public `faucet()` mint.
