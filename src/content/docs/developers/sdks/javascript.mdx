The Mersennet JavaScript SDK (`@mersennet/sdk`) provides a typed interface for the JSON-RPC API, MersennetOrders (on-chain order book), and WebSocket subscriptions. For an end-to-end walkthrough (connect, read the protocol, deposit collateral, place a signed order, read it back) in TypeScript, Python and Go, see [Trade via SDK and RPC](/developers/tutorials/trade-via-sdk/).

:::tip[Privacy / shielded features]
This page covers the **transparent** surface (`eth_*` / `mersennet_*` / `mersennet_orders_*`). For shielded transfers and orders, client-side Noir proving, note scanning, balance/position reconstruction, selective-disclosure reads, and migration, see the dedicated **[Shielded SDK](/developers/privacy/shielded-sdk/)**.
:::

## Quick reference

Connect, place an order, and check a balance, with the SDK or the equivalent raw JSON-RPC calls:

<Tabs syncKey="lang">
  <TabItem label="TypeScript">

```typescript title="quick-reference.ts"
import { Wallet } from 'ethers';
import { MersennetProvider, MersennetOrders } from '@mersennet/sdk';

// Connect
const provider = new MersennetProvider('https://rpc.mersennet.com');
const orders = new MersennetOrders(provider);
console.log('Chain ID:', await provider.getChainId()); // 131071

// Place an order. Every mutating method takes a trailing signer: the SDK
// builds a placeOrder transaction to the CLOB precompile (0x…0100), your
// signer signs it locally, and the SDK broadcasts it via
// eth_sendRawTransaction. The node acknowledges with { accepted, txHash };
// the order is placed when that transaction mines.
const wallet = new Wallet(process.env.PRIVATE_KEY!);
const signer = (tx) => wallet.signTransaction(tx);

const ack = await orders.submitOrder(
  wallet.address, // owner — must be the signer's address
  1,              // market ID (MRSN)
  'buy',
  '0x2c88',       // price: 11400 = $114.00 on MRSN (priceScale 100) — read the scale from getMarkets()
  '0xa',          // size
  'gtc',
  signer
);
console.log('Accepted:', ack.accepted, 'tx:', ack.txHash);

// Check balance
const balance = await provider.getBalance('0xYourAddress');
console.log('Balance (wei):', BigInt(balance).toString());
```

## Installation

```bash
npm install @mersennet/sdk
```

Published on npm as [`@mersennet/sdk`](https://www.npmjs.com/package/@mersennet/sdk) from the [mersennet/sdk-ts](https://github.com/mersennet/sdk-ts) releases (MIT), with a signed provenance statement from GitHub Actions — `npm audit signatures` verifies that the tarball was built from the tagged source. Current version: 0.1.1.

Or from a checkout (`npm install && npm run build` in `sdk-ts/`, then `npm install /path/to/sdk-ts`).

## Quick Start

```javascript
import { MersennetProvider, MersennetOrders } from "@mersennet/sdk";

const provider = new MersennetProvider("https://rpc.mersennet.com");
const orders = new MersennetOrders(provider);

// Query chain
const blockNumber = await provider.getBlockNumber();
const chainId = await provider.getChainId();
console.log("Block:", blockNumber, "Chain ID:", chainId);

// Query balance
const balance = await provider.getBalance("0x7f5ce38fb2553e95dd8ef9182a80bc219c9a0d45");
console.log("Balance (hex):", balance);

// Query order book
const book = await orders.getOrderBook(1);
console.log("Bids:", book.bids, "Asks:", book.asks);
```

## Querying Balances

```javascript
const balance = await provider.getBalance("0xYourAddress");
// Returns hex string, e.g. "0xde0b6b3a7640000"

```

## Sending Transactions

Sign locally and submit via `sendRawTransaction`. The SDK's `sendTransaction` **throws** (`'eth_sendTransaction is disabled; sign the transaction locally and call sendRawTransaction(rawHex)'`) — unlocked-account submission is not supported on any Mersennet node.

```javascript
import { Wallet } from "ethers";

const wallet = new Wallet(process.env.PRIVATE_KEY);
const raw = await wallet.signTransaction({
  to: "0x...",
  value: "0xde0b6b3a7640000", // 1 MRSN in hex
  gasLimit: "0x5208",
  gasPrice: "0x3b9aca00",
  nonce: await provider.getTransactionCount(wallet.address, "pending"),
  chainId: 131071,
});

const txHash = await provider.sendRawTransaction(raw);
console.log("Tx hash:", txHash);
```

:::tip
For transactions from a wallet (e.g., browser), use ethers.js or viem with the Mersennet RPC — they sign locally and submit via `eth_sendRawTransaction` out of the box.
:::

## Interacting with MersennetOrders

MersennetOrders is Mersennet's on-chain order book (CLOB). Use it for limit orders, positions, and collateral.

### Markets, price scale and protocol parameters

```javascript
// On-chain prices are human × priceScale (1 = integer prices; 100 on MRSN/SOL/ARB
// from block 1,569,600 → $0.01 ticks). Never assume integers: read the scale.
const markets = await orders.getMarkets();
const mrsn = markets.find((m) => m.symbol === 'MRSN');
const chainPrice = MersennetOrders.toChainPrice('115.37', mrsn); // 11537n at scale 100
const human = MersennetOrders.toHumanPrice(11537n, mrsn);         // 115.37

// Every consensus switch and live parameter (margin bps, wei per collateral
// unit, insurance fund, bad debt, market scales) in one call.
const protocol = await orders.getProtocol();
console.log(protocol.settlementActive, protocol.maintenanceMarginBps);

// Agent delegation: grants issued by a wallet (one-click trading keys).
const agents = await orders.getAgents(owner);
// Keeper feed: accounts below maintenance margin right now.
const underwater = await orders.getLiquidatable();
```

### Get Order Book

```javascript
const book = await orders.getOrderBook(1);
// book: { bids: [{ price, size }], asks: [{ price, size }] }
// Both sides are sorted by ascending price, so the best bid is the LAST
// element of bids and the best ask is the FIRST element of asks.
console.log("Best bid:", book.bids[book.bids.length - 1]);
console.log("Best ask:", book.asks[0]);
```

### Get Open Orders

```javascript
const openOrders = await orders.getOpenOrders("0xOwnerAddress");
console.log("Open orders:", openOrders);
```

### Get Position

```javascript
const position = await orders.getPosition("0xOwnerAddress", 1);
// position: { size: string, entry_price: string }
console.log("Position size:", position.size, "Entry:", position.entry_price);
```

### Get Collateral

```javascript
const collateral = await orders.getCollateral("0xOwnerAddress");
console.log("Collateral:", collateral);
```

### Submit Order

Every mutating method in `MersennetOrders` requires a trailing signer — a
function `(tx) => Promise<rawSignedHex>` (wrap ethers, viem, or any secp256k1
signer). The SDK builds a `placeOrder` transaction to the CLOB precompile,
your signer signs it locally, and the SDK broadcasts it via
`eth_sendRawTransaction`. Unsigned submission over RPC fails with `-32604`
on public endpoints.

```javascript
import { Wallet } from "ethers";

const wallet = new Wallet(process.env.PRIVATE_KEY);
const signer = (tx) => wallet.signTransaction(tx);

// The node responds with an acknowledgement, not a fill report:
// { accepted: true, txHash: "0x..." }. The order enters the book when
// that transaction mines; read fills back via getOpenOrders/getOrderBook
// or the transaction receipt.
const ack = await orders.submitOrder(
  wallet.address, // owner — must be the signer's address
  1,              // marketId
  "buy",          // "buy" | "sell"
  "0x2c88",       // price: 11400 = $114.00 at priceScale 100
  "0xa",          // size
  "gtc",          // "gtc" | "ioc" | "fok"
  signer
);
console.log("Accepted:", ack.accepted, "tx:", ack.txHash);
```

### Cancel Order

```javascript
// cancelOrder(owner, orderId, signer) — signed; the chain enforces ownership.
await orders.cancelOrder(wallet.address, 123, signer);
```

### Deposit Collateral

`depositCollateral` and `withdrawCollateral` take an amount in **collateral units**, and the unit changes at the settlement switch (block 1,605,600, Sun 20 Sep 2026 ≈ 16:30 UTC): before it one unit is one wei (10¹⁸ units per MRSN), from it one unit is one MRSN. Convert human MRSN amounts with `toCollateralUnits()`, which reads `weiPerCollateralUnit` from `getProtocol()` so the same code works in both eras; never hard-code `1e18`.

```javascript
// Escrow 1 MRSN from the signer's native balance.
const units = await orders.toCollateralUnits("1");
await orders.depositCollateral(wallet.address, units.toString(), signer);
```

### Withdraw Collateral

Sends a transaction to the CLOB precompile (the chain validates margin first):

```javascript
const units = await orders.toCollateralUnits("0.5");
await orders.withdrawCollateral(wallet.address, units.toString(), signer);

// Units per MRSN in the current era: 10n ** 18n before the settlement switch, 1n after.
console.log(await orders.collateralUnitsPerMrsn());
```

### Agent keys and liquidations

`setAgent` lets a second key place and cancel orders **as** your account (it can never deposit or withdraw); the terminal's one-click trading is built on it. `getLiquidatable` and `liquidate` are the keeper surface that activates with the settlement switch. `setAgent`, `revokeAgent` and `getAgents` have been live since block 1,569,600 (19 Sep 2026, 19:23 UTC); `getLiquidatable`, `isLiquidatable` and `liquidate` activate at block 1,605,600 (20 Sep ≈ 16:30 UTC).

```javascript
import { Wallet } from "ethers";

const owner = new Wallet(process.env.PRIVATE_KEY);
const ownerSigner = (tx) => owner.signTransaction(tx);

// Grant a fresh key for ~7 days (≈ 288,000 blocks at 2.1 s); 0 = no expiry.
// The agent pays gas for its own transactions, so send it a little MRSN first.
const agent = Wallet.createRandom();
const head = await provider.getBlockNumber();
await orders.setAgent(owner.address, agent.address, head + 288_000, ownerSigner);

// The agent sends and signs its own transaction (first argument = the sender,
// so the SDK fetches the agent's nonce); the precompile books the order on the
// owner's account — orders, positions and fills stay on the owner.
const agentSigner = (tx) => agent.signTransaction(tx);
const mrsn = (await orders.getMarkets()).find((m) => m.symbol === "MRSN");
await orders.submitOrder(
  agent.address, 1, "buy",
  MersennetOrders.toChainPrice("114", mrsn).toString(), "1", "gtc",
  agentSigner
);

// Inspect and revoke.
console.log(await orders.getAgents(owner.address)); // { active, agents: [{ agent, expiresAtBlock, expired }], ... }
await orders.revokeAgent(owner.address, agent.address, ownerSigner);

// Keeper loop: accounts below maintenance margin, then liquidate them.
// Anyone may call; the keeper earns half of the 1% fee into its own collateral.
for (const account of await orders.getLiquidatable()) {
  const ack = await orders.liquidate(owner.address, account, ownerSigner);
  console.log("liquidate", account, ack.txHash);
}
```

### Use Precompile Directly

For low-level control, use the precompile encoders:

```javascript
import {
  MersennetPrecompile,
  encodePlaceOrder,
  encodeGetPosition,
  encodeGetCollateral,
} from "@mersennet/sdk";

// Encode call data for eth_call
const getPositionData = encodeGetPosition(1);
const result = await provider.call({
  from: "0x...",
  to: MersennetPrecompile.ADDRESS, // 0x0000000000000000000000000000000000000100
  data: getPositionData,
});

// Encode place order for transaction
const placeOrderData = encodePlaceOrder(
  1,      // marketId
  true,   // isBuy
  BigInt(1000000),  // price
  BigInt(10),       // size
  0       // tif: 0=GTC, 1=IOC, 2=FOK
);
```

## WebSocket Subscriptions

```javascript
import { MersennetProvider, MersennetSubscription } from "@mersennet/sdk";

const provider = new MersennetProvider(
  "https://rpc.mersennet.com",
  "wss://rpc.mersennet.com"
);
const sub = new MersennetSubscription(provider);

await sub.connect();

// New blocks
const blockSubId = await sub.onNewBlock((block) => {
  console.log("New block:", block.number);
});

// MersennetOrders trades
const tradeSubId = await sub.onTrade((trade) => {
  console.log("Trade:", trade);
}, 1); // optional: market ID

// Order book updates
// MersennetOrdersBook is accepted by the node but not emitted in 0.7.0 — poll orders.getOrderBook(1) for book state.
const bookSubId = await sub.onBookUpdate((update) => {
  console.log("Book update:", update);
}, 1);

// Unsubscribe
sub.unsubscribe(blockSubId);
```

:::note
The public WebSocket endpoint `wss://rpc.mersennet.com` supports `eth_subscribe` (`newHeads`, `newPendingTransactions`, `logs`) and `mersennet_subscribe` (`MersennetOrdersTrades`, `newShieldedRoot`, `newStateProof`, …); every other JSON-RPC call must go over HTTPS. `MersennetOrdersBook` subscriptions are accepted but node 0.7.0 never emits them — poll `getOrderBook` instead. A node you run yourself needs `ws.enabled = true`.
:::

## Full API Reference

| Class | Method | Description |
|-------|--------|-------------|
| `MersennetProvider` | `getBlockNumber()` | Latest block number |
| | `getBalance(address)` | Account balance (hex) |
| | `getTransactionCount(address)` | Nonce |
| | `getBlockByNumber(n, full)` | Block by number |
| | `getBlockByHash(hash, full)` | Block by hash |
| | `getTransactionReceipt(hash)` | Transaction receipt |
| | `call(tx)` | eth_call |
| | `estimateGas(tx)` | eth_estimateGas |
| | `sendTransaction(tx)` | **Disabled — throws.** Sign locally and use `sendRawTransaction(rawHex)` |
| | `sendRawTransaction(rawHex)` | eth_sendRawTransaction (locally signed) |
| | `getChainId()` | Chain ID |
| | `getGasPrice()` | Gas price (hex) |
| | `getCode(address)` / `getCodeHash(address)` | Contract bytecode / code hash |
| | `getCodeAttestation(address)` | Code-publication attestation |
| | `getStorageAt(address, slot)` | Storage slot value |
| | `viewNotes(grantIdHex, opts?)` | Grant-gated encrypted notes (selective disclosure) |
| | `viewBalances(grantIdHex, opts?)` | Grant-gated notes + spent nullifiers for reconstruction |
| | `viewPositions(grantIdHex)` / `viewOrders(grantIdHex)` | Grant-gated trading reconstruction context |
| `MersennetOrders` | `getOrderBook(marketId)` | Order book (`{ bids, asks }`, both sorted by ascending price) |
| | `getOpenOrders(owner)` | Open orders for an owner |
| | `getPosition(owner, marketId)` | Position (`{ size, entry_price }`) via `eth_call` on the precompile |
| | `getCollateral(owner)` | Collateral balance in collateral units, via `eth_call` on the precompile |
| | `submitOrder(owner, marketId, side, price, size, tif, signer)` | Submit an order (signed precompile tx); `owner` is the transaction sender and must be the signer's address — when the sender is an agent key, the order lands on the granting owner's account |
| | `submitBatchOrder({ owner, orders }, signer)` | Submit several orders in sequence, each a signed tx (returns nothing; read back with `getOpenOrders`) |
| | `cancelOrder(owner, orderId, signer)` | Cancel an order (signed precompile tx; the chain enforces ownership) |
| | `depositCollateral(owner, amount, signer)` | Deposit (signed tx); `amount` in collateral units — use `toCollateralUnits` |
| | `withdrawCollateral(owner, amount, signer)` | Withdraw (signed tx; the chain validates margin first); `amount` in collateral units |
| | `collateralUnitsPerMrsn()` | Collateral units per MRSN in the current era (`10n ** 18n` before the settlement switch, `1n` from it), read from `getProtocol()` |
| | `toCollateralUnits(mrsn)` | Human MRSN amount (`"10.5"`) → integer collateral units for the current era (floor) |
| | `isLiquidatable(owner)` | Whether an account is below maintenance margin (`mersennet_orders_isLiquidatable`) |
| | `getProtocol()` | Every CLOB consensus switch and live parameter: margin bps, `weiPerCollateralUnit`, insurance fund, bad debt, each market's `priceScale` |
| | `getMarkets()` | Listed markets with tick/lot sizes and `priceScale` (on-chain price = human × `priceScale`) |
| | `MersennetOrders.toChainPrice(human, market)` | Static: human price → on-chain price for a market (rounds to the nearest unit) |
| | `MersennetOrders.toHumanPrice(chain, market)` | Static: on-chain price → human price for a market |
| | `getAgents(owner)` | Agent keys granted by `owner`, plus whether delegation is active on the network |
| | `setAgent(owner, agent, expiresAtBlock, signer)` | Let `agent` trade for `owner` until `expiresAtBlock` (0 = no expiry; otherwise at most the current height + 3,900,000 blocks ≈ 90 days); signed by the owner |
| | `revokeAgent(owner, agent, signer)` | Revoke an agent; signed by the owner that granted it |
| | `getLiquidatable()` | Accounts below maintenance margin at the head (empty before the settlement switch) |
| | `liquidate(keeper, account, signer)` | Liquidate `account` (anyone may call; the keeper earns half of the 1% fee into its collateral) |
