# Internal documentation

Source material that is not rendered on docs.mersennet.com:

- `ARCHITECTURE.md`, `TECHNICAL_REFERENCE.md`, `whitepaper.md` — deep engineering references
- `adr/` — architecture decision records (ADR-001 … ADR-019)
- `runbooks/` — operational runbooks (testnet bootstrap, fork activation)
- `security/` — cryptography spec, privacy invariants, audit packet
- `delivery/`, `internal/` — workstream close-out and planning notes
- `fundraising/`, `STRATEGIC_POSITIONING.md`, `PITCH_DECK*.md`, `TEAM.md` — corporate material (keep this repo private while these live here)
- `TOKENOMICS.md` — canonical token economics

The rendered documentation site lives at the root of this repository
(`src/content/docs/`). When a fact changes, update both the site page and
the reference here.
