Connect to Mersennet testnet with MetaMask or any EVM-compatible wallet — setup takes under a minute.

## Option 1: MetaMask (Manual Setup)

### Step 1: Open MetaMask

1. Install [MetaMask](https://metamask.io/) if you haven't already.
2. Click the network dropdown in the top-left of MetaMask.

### Step 2: Add Network

1. Select **Add network** → **Add a network manually**.
2. Enter the following:

| Field | Value |
|-------|-------|
| **Network name** | Mersennet Testnet |
| **RPC URL** | `https://rpc.mersennet.com` |
| **Chain ID** | `131071` |
| **Currency symbol** | MRSN |
| **Block explorer URL** | `https://explorer.mersennet.com` |

3. Click **Save**.

### Step 3: Switch Network

Select **Mersennet Testnet** from the network dropdown. You're ready to use Mersennet.

This triggers the following MetaMask call:

```javascript
await window.ethereum.request({
  method: 'wallet_addEthereumChain',
  params: [{
    chainId: '0x1FFFF',
    chainName: 'Mersennet Testnet',
    nativeCurrency: { name: 'MRSN', symbol: 'MRSN', decimals: 18 },
    rpcUrls: ['https://rpc.mersennet.com'],
    blockExplorerUrls: ['https://explorer.mersennet.com']
  }]
});
```

Click **Approve** in MetaMask to add the network.

---

## Option 3: Other EVM Wallets

Any EVM-compatible wallet works — Rabby, Frame, Rainbow, hardware wallets through MetaMask, or programmatic wallets via ethers.js/viem. Use the same network parameters as above. Transactions are standard EIP-155 signed transactions, so nothing about your signing flow changes.

---

## Verify Your Setup

1. **Network**: Ensure "Mersennet Testnet" (or equivalent) is selected.
2. **Balance**: You need MRSN for gas. Use the [faucet](/getting-started/faucet/) to get testnet tokens.
3. **Explorer**: Visit https://explorer.mersennet.com to view blocks and transactions.
