The Mersennet Python SDK (`mersennet-sdk`) provides a client for the JSON-RPC API, MersennetOrders (on-chain order book), and WebSocket subscriptions.

## Quick reference

Connect, place an order, and check a balance, with the SDK or the equivalent raw JSON-RPC calls:

<Tabs syncKey="lang">
  <TabItem label="Python">

```python title="quick_reference.py"
import os

from eth_account import Account
from mersennet import MersennetProvider, MersennetOrders

# Connect
provider = MersennetProvider("https://rpc.mersennet.com")
orders = MersennetOrders(provider)
print("Chain ID:", provider.chain_id())  # 131071

# Place an order: sign a placeOrder transaction to the CLOB precompile
# (0x…0100) locally with eth-account and submit it via
# eth_sendRawTransaction. The order is placed when the transaction mines.
PRECOMPILE = "0x0000000000000000000000000000000000000100"

def encode_place_order(market_id: int, is_buy: bool, price: int, size: int, tif: int) -> str:
    # placeOrder(uint64 marketId, bool isBuy, uint256 price, uint256 size, uint8 tif)
    words = [market_id, 1 if is_buy else 0, price, size, tif]
    return "0x4c570d73" + "".join(format(w, "064x") for w in words)

acct = Account.from_key(os.environ["PRIVATE_KEY"])
signed = acct.sign_transaction({
    "to": PRECOMPILE,
    "data": encode_place_order(1, True, 11400, 10, 0),  # market 1 = MRSN, GTC buy at $114.00 (price_scale 100 — read it from get_markets())
    "value": 0,
    "gas": 300_000,
    "gasPrice": int(provider.gas_price(), 16),
    "nonce": provider.get_nonce(acct.address),  # already an int
    "chainId": 131071,
})
tx_hash = provider.send_raw_transaction(signed.raw_transaction.hex())
print("tx:", tx_hash)

# Check balance
balance = provider.get_balance("0xYourAddress")
print("Balance (wei):", int(balance, 16))
```

curl -X POST https://rpc.mersennet.com \
  -H "Content-Type: application/json" \

## Quick Start

```python
from mersennet import MersennetProvider, MersennetOrders

provider = MersennetProvider("https://rpc.mersennet.com")
orders = MersennetOrders(provider)

# Query chain
block_num = provider.block_number()
chain_id = provider.chain_id()
print(f"Block: {block_num}, Chain ID: {chain_id}")

# Query balance
balance = provider.get_balance("0x7f5ce38fb2553e95dd8ef9182a80bc219c9a0d45")
print(f"Balance: {balance}")

# Query order book
book = orders.get_order_book(1)
print(f"Bids: {book.bids}, Asks: {book.asks}")
```

## Basic Usage

### Block and Chain Info

```python
# Latest block number
block_num = provider.block_number()

# Block by number
block = provider.get_block("latest", include_txs=False)
block = provider.get_block(12345, include_txs=True)

# Chain ID
chain_id = provider.chain_id()

# Gas price (hex)
gas_price = provider.gas_price()
```

### Account Queries

```python
# Balance (hex string)
balance = provider.get_balance("0xYourAddress")

# Nonce (transaction count)
nonce = provider.get_nonce("0xYourAddress")
```

### Transaction Queries

```python
# Transaction by hash
tx = provider.get_transaction("0xTxHash")

# Transaction receipt
receipt = provider.get_transaction_receipt("0xTxHash")
```

### Contract Calls (eth_call)

```python
# Simulate a contract call
result = provider.call({
    "from": "0x...",
    "to": "0x...",
    "data": "0x...",
})
```

### Sending Raw Transactions

```python
# Send signed raw transaction
tx_hash = provider.send_raw_transaction("0xSignedTxHex")
```

:::note
`eth_sendRawTransaction` accepts standard Ethereum RLP-encoded transactions (e.g. signed with `eth-account`/web3.py) as well as Mersennet's custom binary format.
:::

## MersennetOrders

### Markets, price scale and protocol parameters

```python
markets = orders.get_markets()          # [{'id', 'symbol', 'tick_size', 'lot_size', 'last_price', 'price_scale', 'status'}]
mrsn = next(m for m in markets if m["symbol"] == "MRSN")
chain_price = orders.to_chain_price(115.37, mrsn["price_scale"])   # 11537 at scale 100
human = orders.to_human_price(11537, mrsn["price_scale"])           # 115.37
protocol = orders.get_protocol()        # switches, margin bps, wei per collateral unit, insurance fund, bad debt
agents = orders.get_agents(owner)       # agent keys granted by `owner` (setAgent; one-click trading keys)
underwater = orders.get_liquidatable()  # keeper feed: accounts below maintenance margin (empty before the settlement switch)
```

### Collateral units and deposits

`depositCollateral` / `withdrawCollateral` take an amount in **collateral units**, and the unit changes at the settlement switch (block 1,605,600, Sun 20 Sep 2026 ≈ 16:30 UTC): one unit is one wei before it (10¹⁸ units per MRSN) and one MRSN from it. `to_collateral_units()` converts a human MRSN amount for the current era by reading `weiPerCollateralUnit` from `get_protocol()`, so the same code works before and after the switch; never hard-code `10**18`.

```python
units_per_mrsn = orders.collateral_units_per_mrsn()   # 10**18 before the switch, 1 from it
units = orders.to_collateral_units("10.5")            # int, for depositCollateral / withdrawCollateral

# Deposit: depositCollateral(uint256 amount), selector 0xbad4a01f — a signed tx like placeOrder
# (`acct` and `PRECOMPILE` as in the quick reference above).
def encode_deposit_collateral(units: int) -> str:
    return "0xbad4a01f" + format(units, "064x")

signed = acct.sign_transaction({
    "to": PRECOMPILE,
    "data": encode_deposit_collateral(units),
    "value": 0,
    "gas": 200_000,
    "gasPrice": int(provider.gas_price(), 16),
    "nonce": provider.get_nonce(acct.address),
    "chainId": 131071,
})
tx_hash = provider.send_raw_transaction(signed.raw_transaction.hex())

# Read it back: getCollateral() (selector 0x5c1548fb) returns the caller's balance in collateral units.
raw = provider.call({"from": acct.address, "to": PRECOMPILE, "data": "0x5c1548fb"})
collateral_units = int(raw, 16) if raw not in ("", "0x") else 0
print("collateral (MRSN):", collateral_units / units_per_mrsn)
```

### Place Order

`orders.place_order()` and `orders.cancel_order()` are **deprecated and raise
`NotImplementedError`**: the unsigned owner-field RPC was removed for security
(it let anyone trade as anyone). Orders are now signed transactions to the
CLOB precompile (`0x0000000000000000000000000000000000000100`). Sign the
`placeOrder` calldata locally with `eth-account`/web3.py and submit it via
`provider.send_raw_transaction()`:

```python
import os

from eth_account import Account

PRECOMPILE = "0x0000000000000000000000000000000000000100"

def encode_place_order(market_id: int, is_buy: bool, price: int, size: int, tif: int) -> str:
    # placeOrder(uint64 marketId, bool isBuy, uint256 price, uint256 size, uint8 tif)
    # tif: 0 = GTC, 1 = IOC, 2 = FOK
    words = [market_id, 1 if is_buy else 0, price, size, tif]
    return "0x4c570d73" + "".join(format(w, "064x") for w in words)

acct = Account.from_key(os.environ["PRIVATE_KEY"])
signed = acct.sign_transaction({
    "to": PRECOMPILE,
    "data": encode_place_order(1, True, 11400, 10, 0),  # 11400 = $114.00 at price_scale 100
    "value": 0,
    "gas": 300_000,
    "gasPrice": int(provider.gas_price(), 16),
    "nonce": provider.get_nonce(acct.address),  # already an int
    "chainId": 131071,
})
tx_hash = provider.send_raw_transaction(signed.raw_transaction.hex())
# The order is placed when this transaction mines; read fills back via
# get_order_book()/get_trades() or the MersennetOrdersTrades WebSocket topic.
```

### Cancel Order

Same flow with the `cancelOrder(uint256 orderId)` calldata (selector
`0x514fcac7`); the chain enforces order ownership:

```python
def encode_cancel_order(order_id: int) -> str:
    return "0x514fcac7" + format(order_id, "064x")
```

### Create Market

Market creation is the `createMarket(symbol, tickSize, lotSize)` precompile
call (100 MRSN listing fee), submitted as a signed transaction like
`placeOrder` above — see [Deployed Contracts](/resources/contracts/) for the
Solidity interface.

### MersennetOrders reference

| Method | Description |
|--------|-------------|
| `get_order_book(market)` | Order book (`bids` / `asks`, both sorted by ascending price) |
| `get_trades(market)` | Recent trade events for a market (`mersennet_getDomainEvents`) |
| `get_positions(address, market=None)` | `getPosition(uint64)` via the precompile: `{market, size (signed int, negative = short), entry_price (chain price), raw}`; without `market`, every non-zero position keyed by market id (SDK ≥ 0.1.1) |
| `get_markets()` | Listed markets with `tick_size`, `lot_size`, `last_price`, `price_scale`, `status` |
| `to_chain_price(human, price_scale)` / `to_human_price(chain, price_scale)` | Static: human ↔ on-chain price (on-chain = human × `price_scale`) |
| `get_protocol()` | Every CLOB consensus switch and live parameter (`mersennet_orders_getProtocol`) |
| `collateral_units_per_mrsn()` | Collateral units per MRSN in the current era (`10**18` before the settlement switch, `1` from it) |
| `to_collateral_units(mrsn)` | Human MRSN amount (`"10.5"`, `10`, `Decimal`) → integer collateral units for the current era (floor) |
| `get_agents(owner)` | Agent keys granted by `owner` and whether delegation is active (`mersennet_orders_getAgents`) |
| `get_liquidatable()` | Accounts below maintenance margin at the head (keeper feed; empty before the settlement switch) |
| `place_order(...)` / `cancel_order(order_id)` | **Deprecated** — raise `NotImplementedError`; submit signed precompile transactions as shown above |

There are no Python signing helpers yet: build the calldata, sign with `eth-account`, and submit via `provider.send_raw_transaction()`. The same applies to `setAgent` / `revokeAgent` (`setAgent(address agent, uint64 expiresAtBlock)`, selector `0xb845309c`; `revokeAgent(address agent)`, selector `0x7da6ac0d`) and the keeper call `liquidate(address account)` (selector `0x2f865568`).

## WebSocket Subscriptions

```python
from mersennet import MersennetSubscriber

# MersennetSubscriber takes the WebSocket URL directly
subscriber = MersennetSubscriber("wss://rpc.mersennet.com")

# Connect
subscriber.connect()

# Subscribe to new blocks
def on_block(block):
    print("New block:", block)

sub_id = subscriber.subscribe_blocks(on_block)

# Subscribe to MersennetOrders trades for a market
def on_trade(trade):
    print("Trade:", trade)

trade_sub_id = subscriber.subscribe_trades(1, on_trade)

# Subscribe to logs
def on_log(log):
    print("Log:", log)

log_sub_id = subscriber.subscribe_logs(on_log, address="0x...")

# Unsubscribe
subscriber.unsubscribe(sub_id)
subscriber.disconnect()
```

:::tip
The public WebSocket endpoint `wss://rpc.mersennet.com` supports `eth_subscribe` (`newHeads`, `newPendingTransactions`, `logs`) and `mersennet_subscribe` (`MersennetOrdersTrades`, `newShieldedRoot`, `newStateProof`, …); every other JSON-RPC call must go over HTTPS. A node you run yourself needs `ws.enabled = true`.
:::

## Error Handling

```python
from mersennet import MersennetProvider
from mersennet.provider import MersennetError

provider = MersennetProvider("https://rpc.mersennet.com")

try:
    balance = provider.get_balance("0x...")
except MersennetError as e:
    print(f"RPC error: {e}, code: {e.code}")
```

## Dependencies

- **Python 3.10+**
- **requests** (recommended for HTTP)
- **websocket-client** (for WebSocket subscriptions)

The SDK can fall back to `urllib` if `requests` is not installed, but `requests` is recommended for production use.
