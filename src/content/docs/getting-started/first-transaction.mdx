## Step 1: Send MRSN

### Using MetaMask

1. Click **Send** in MetaMask.
2. Enter the recipient address.
3. Enter the amount in MRSN.
4. Confirm the transaction.

### Using ethers.js

```javascript
import { ethers } from 'ethers';

const provider = new ethers.JsonRpcProvider('https://rpc.mersennet.com');
const wallet = new ethers.Wallet('YOUR_PRIVATE_KEY', provider);

const tx = await wallet.sendTransaction({
  to: '0xRecipientAddress',
  value: ethers.parseEther('0.1'),
  gasLimit: 21000,
});

console.log('Tx hash:', tx.hash);
await tx.wait();
console.log('Confirmed!');
```

> **Security Warning:** Never use real private keys in code. Use environment variables or a key management solution. Never commit private keys to version control.

### Using the Mersennet SDKs

Prefer the official SDKs or raw JSON-RPC? The same transfer in TypeScript (`@mersennet/sdk`), Python (`mersennet-sdk`), Go, and curl:

:::note[SDK availability]
The Mersennet SDKs are public on GitHub — [sdk-ts](https://github.com/mersennet/sdk-ts), [sdk-python](https://github.com/mersennet/sdk-python), [sdk-go](https://github.com/mersennet/sdk-go) (MIT). They are not on npm/PyPI yet; install the v0.1.0 release from GitHub: `npm install github:mersennet/sdk-ts#semver:^0.1`, `pip install "git+https://github.com/mersennet/sdk-python.git@v0.1.1"`, `go get github.com/mersennet/sdk-go@latest`. Everything below also works with ethers.js/viem or raw JSON-RPC.
:::

```typescript title="send-mrsn.ts"
import { MersennetProvider } from '@mersennet/sdk';

const provider = new MersennetProvider('https://rpc.mersennet.com');

// Sign the transaction locally (e.g. with ethers.js), then broadcast

console.log('Status:', receipt?.status);
```

```go title="send_mrsn.go"
package main

import (
	"fmt"
	"log"

	mersennet "github.com/mersennet/sdk-go"
)

func main() {
	provider := mersennet.NewProvider("https://rpc.mersennet.com")

	// Sign the transaction locally, then broadcast the raw bytes
	// via eth_sendRawTransaction.
	txHash, err := provider.SendRawTransaction("0xSignedTxHex")
	if err != nil {
		log.Fatal(err)
	}
	fmt.Println("Tx hash:", txHash)
}
```

## Step 2: Deploy a Simple Contract

Deploy a minimal Solidity contract using ethers.js. First, compile your contract with Hardhat or Foundry, then deploy:

```javascript
import { ethers } from 'ethers';

const provider = new ethers.JsonRpcProvider('https://rpc.mersennet.com');
const wallet = new ethers.Wallet('YOUR_PRIVATE_KEY', provider);

// Load compiled artifact (from Hardhat: artifacts/contracts/Counter.sol/Counter.json)
const artifact = require('./artifacts/contracts/Counter.sol/Counter.json');
const factory = new ethers.ContractFactory(artifact.abi, artifact.bytecode, wallet);

const contract = await factory.deploy();
await contract.waitForDeployment();

console.log('Deployed at:', await contract.getAddress());
```

> **Security Warning:** Never use real private keys in code. Use environment variables or a key management solution. Never commit private keys to version control.

**Minimal Solidity example (Counter.sol):**

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract Counter {
    uint256 public count;

    function increment() external {
        count++;
    }
}
```

:::tip
For production deployments, use [Hardhat](/developers/quick-start/hardhat) or [Foundry](/developers/quick-start/foundry) to compile, test, and deploy. They handle compilation, gas estimation, and verification.
:::

## Step 3: View on the Explorer

1. Copy the transaction hash from your wallet or script output.
2. Open the [block explorer](https://explorer.mersennet.com).
3. Paste the hash into the search bar.
4. View the transaction details, block number, gas used, and status.

For contract deployments, the explorer shows the contract address. You can click it to see the contract page and interact with it (if verified).
